## Render Mermaid → SVG/PNG

Install mermaid-cli:
```bash
npm install -g @mermaid-js/mermaid-cli
```

Convert all `.mmd` to `.svg`:
```bash
for f in figures/*.mmd; do
    mmdc -i "$f" -o "${f%.mmd}.svg" \
         --backgroundColor white \
         --width 1200
done
```

Or single file:
```bash
mmdc -i figures/dual_track_architecture.mmd \
     -o figures/dual_track_architecture.svg
```

## Regenerate finger distribution charts

```bash
python visualize_finger_distribution.py \
    --midi "input_songs/Canon In D - Pachelbel  EASY Piano Tutorial.mid"
```

Outputs replace existing PNG files in this directory.

## Convention

- PNG figures (matplotlib outputs) are 300 dpi for print
- Mermaid sources are committed; SVG outputs are gitignored
  (regenerated by Make target or above commands)
- Filenames use `snake_case`
- Each figure has a caption in the chapter that embeds it
